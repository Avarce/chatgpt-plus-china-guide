## 先搞明白：为什么国内充 Plus 这么难

在 ChatGPT 网页结账页付款被拒，多数不是操作错了。按 OpenAI 帮助中心的说法，一张卡能不能付，先看三件事：发卡银行在哪里、你本人在哪里、账单信息和银行登记的是否一致。搞懂下面四点，后面的报错大多能自己判断：

- **发卡银行要在 OpenAI 支持的国家和地区。** OpenAI 写明，付款用的卡必须由支持地区的银行发行（[Why was my credit card declined?](https://help.openai.com/en/articles/7232916-why-was-my-credit-card-declined)）。2026 年 10 月 27 日查看[支持的国家和地区](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)，中国大陆、香港、澳门都不在名单里。看的是发卡银行，不是卡面上的 Visa、Mastercard 标志：国内银行发的双币卡、全币卡，发卡银行仍在中国大陆。
- **海外银行发的卡，也可能被拒。** OpenAI 的排查清单里，第一项就是核对卡号、有效期、安全码和账单地址（含邮编），要和发卡银行登记的一致；它还要求你本人和发卡银行都在支持地区，任何一方不在，付款都可能被拒（[Plus / Pro 续费付款排查](https://help.openai.com/en/articles/7242622-troubleshooting-chatgpt-plus-or-pro-renewal-payments)）。OpenAI 没写怎么判断你在哪里。我们的经验是：卡的账单地址、注册 ChatGPT 时和付款时的网络出口（IP）分在不同国家，更容易被拒，尽量让它们落在同一个国家。
- **结账页不说原因。** 付款没通过时，结账页顶部只显示「付款未获批」（Payment was not approved）或「您的银行卡被拒绝了」（Your card has been declined.）。OpenAI 说银行通常不会把拒绝的具体原因告诉他们，要问原因只能找发卡银行。
- **$0 的免费试用也要验卡。** 部分免费试用要先绑一张有效的付款方式，试用结束后用这张卡自动续费（[免费试用与优惠订阅 FAQ](https://help.openai.com/en/articles/8381046-chatgpt-promotional-subscriptionsfree-trial-invites-faq)）。所以当天应付 $0，卡照样要过这一关，下图就是这样。

## 四条路，逐条讲真实成本与风险

### 路线 A：官方直付（有海外卡就选它，最省钱最正规）

**适合谁：** 手里有一张能过 Stripe 的海外信用卡（或能刷海外亲友的卡、绑了海外卡的 PayPal）的人。

**怎么做：** 挂一个稳定干净的美区节点 → chatgpt.com → Settings → Upgrade → 填卡号、有效期、CVV、美国账单地址 → 提交。$20/月 + 当地税。

**真实成本：** 官方原价，没有任何溢价。

**优点：** 最正规，订阅绑在你自己账号上，自动续费、稳定。

**缺点 / 注意：** 前提是「你真有一张能用的海外卡」——绝大多数国内用户卡在这一步，所以才有后面三条路。别用国内双币卡硬试超过一两次，失败多了会给账号累加风控标签。

**变体：** 海外亲友代付。如果家人朋友在国外，可以让他们用自己的卡登录你的账号帮你订阅一次，之后每月自动扣他们的卡，你再按月把钱转给他们。零溢价、最省钱，缺点是对方换卡/销卡时你的订阅会断，得记得结清。适合有稳定海外关系的人，但别把「找陌生代付中介」当成这一类——那本质上是路线 D，还没有售后。

### 路线 B：海外虚拟信用卡（技术党可玩，但 2026 年基本团灭）

**适合谁：** 不怵技术、愿意自己一步步搞、未来还想订别的海外服务的人。

**核心原理：** 在海外发卡平台开一张虚拟 Visa/Mastercard，充值美元，再挂美区节点到官网绑卡支付，相当于把自己变成一个「海外用户」。

2026 年的现实——这条路已经很难走了：

- 前两年国内用户量最大的几家平台接连停运：野卡 WildCard、Depay / Dupay（2025 年底正式关服）、BinGoCard、OneKey 等陆续退场，支持人民币直充的虚拟卡基本绝迹。老用户余额能不能全额提出，全看平台良心。
- 还在运营的，几乎清一色是只支持 USDT 充值的加密 U 卡：要先买币、要过 KYC、开卡费 + 月费 + 手续费叠起来一年多花不少，对普通人门槛很高。
- 平台跑路是真实发生过的风险，这类服务处在跨境支付监管的灰色地带，随时可能消失。

**给还想走这条路的人一条实操建议：** 无论用哪家，别一次性充太多钱进去，单次充够开一次订阅（$25–30）就行，别把大额资金锁在平台里。

**优点：** 一卡多用（Netflix / Spotify 等都能绑）；账号完全自主。

**缺点 / 注意：** 门槛高、只收 USDT 的居多；各种费用叠起来比 $20 贵不少；对隐私敏感的人不友好；平台跑路风险始终悬着。

### 路线 C：支付宝买美区 Apple 礼品卡，用 iPhone 订阅 ChatGPT Plus（亲测）

**适合谁：** 有 iPhone 或 iPad、愿意准备一个美区 Apple ID 的人。订阅最终绑定在你登录的 OpenAI 账号上，开通后网页端、Mac、安卓都能正常使用；只有购买礼品卡、兑换和完成 Apple 内购这几步需要苹果设备。

**先分清两个不同的动作：**

1. **在支付宝切换到美国城市**，是为了在首页找到「大牌礼卡」和 Pockyt 礼品卡入口。
2. **在 App Store 使用美区 Apple ID**，是为了兑换美区礼品卡并用余额支付 ChatGPT Plus。设置账单地址时 State 选 **Oregon（OR）**，不加销售税（[为什么](#apple-billing-oregon)）。

更省事的做法是单独准备一个美区 Apple ID，只用于 App Store 的「媒体与购买项目」；主力 iCloud 账号不必跟着改区。如果你选择把现有 Apple ID 改成美区，Apple 才会要求先用完余额、取消现有订阅并等订阅期结束。改区和付款方式选 None 的步骤见[下文](#apple-id-none)。

**为什么这条路线稳定：** 付款由 Apple App Store 处理，不走 OpenAI 网页端的 Stripe 支付流程。礼品卡进入你自己的美区 Apple ID，ChatGPT Plus 则开通到你本人登录的 OpenAI 账号。

**本次实测成本：** 准备一个月的订阅余额，10 月 13 日复测是 **¥134.44**（7 月 18 日实付 ¥135.98）。汇率会变化，购买时以 Pockyt 和 App Store 页面显示为准；每次的汇率和明细见下面[实测流程](#支付宝买美区礼品卡实测流程附截图)里的表。Pockyt 缺货时用 [SEAGM](#seagm)，11 月 6 日实付 ¥138.13。

**完整流程（建议按这个顺序做）：**

1. **先确认有美区 Apple ID。** 已经有的朋友，请直接看第 2 步买卡。还没有的话，可以把现有 Apple ID 改成美区，不过还是比较推荐重新注册一个美区 Apple ID：更方便，不用来回切换地区，国区账号留着分开使用。付款方式选 None，账单地址填 Oregon（OR），步骤和截图见[下文](#apple-id-none)。
2. **在支付宝买 $20 美区 App Store 礼品卡。** 切到美国城市 → 首页「超值抢购」里的「大牌礼卡低至9折」→ 滑到页面底部点 Pockyshop → 地区选美国，点 App Store & iTunes USA → 填收码邮箱并付款。截图见[实测流程](#支付宝买美区礼品卡实测流程附截图)；首页找不到这个入口或搜不到 Pockyt，用[直达链接](#pockyt-direct-link)。Pockyt 缺货时改用 [SEAGM](#seagm)。
3. **在 App Store 兑换礼品卡，再到 iOS 版 ChatGPT App 里升级 Plus**，用余额付款，确认总额是 $19.99。见[拿到兑换码后](#apple-redeem-subscribe)。新注册的 Apple ID，先买一两个便宜 App 再订，见[这一条](#apple-new-account)。
4. **付款时卡住了：** 提示「必须提供付款信息才能继续购买」，看[账单地址改 Oregon](#apple-payment-info-required)；弹出「购买未完成，提交申请至 Apple 支持以供审核」，看[「购买未完成」怎么办](https://github.com/Avarce/apple-purchase-not-completed)。

6. **大额卡我们没试过。** 这次买 $20，只要求绑手机号。LINUX DO 上有人发帖问 200 美元的卡为什么买不了；要买大额，先问 SEAGM 右下角的在线客服（LiveChat）再付款。订 Plus 只需要 $20。

<a id="apple-id-none"></a>

#### Apple ID 改成美区：付款方式选 None（附截图）

**已经有美区 Apple ID 的话，这一节可以跳过，直接往下看[兑换和订阅](#apple-redeem-subscribe)。** 还没有的话有两种办法：比较推荐**重新注册一个美区 Apple ID**，更方便，不用来回切换地区，国区账号留着分开使用；注册时国家或地区选美国，付款方式选「无」（Apple 的[创建账户说明](https://support.apple.com/zh-cn/108647)里这一步可以选「无」），账单地址填 Oregon；另一种是把现有 Apple ID 改成美区。下面是改区的实测（2026 年 10 月 16 日，电脑浏览器，全程不用绑卡）。

**动手前先开美国节点**，用全局模式，尽量选干净的 IP。付款方式里能不能选 None，和 Apple 判断你当前在哪里有关，原因见下面的[看不到 None 怎么办](#apple-id-none-missing)。

**① 个人信息 → 国家/地区。** 打开 [account.apple.com](https://account.apple.com)（旧地址 appleid.apple.com 会跳到这里），登录要改区的 Apple ID，在「个人信息（Personal Information）」里点「国家/地区（Country / Region）」。

</p>

**② 选 United States，点 Continue。** 弹窗会提示改完地区后要更新付款方式，下一步就是。

**③ 点开 Payment Type 下拉框，选最后一项 None。** 弹出「New Payment Method」时，Payment Type 默认显示 Credit / Debit Card，下面跟着一排填卡的输入框，看起来像必须绑卡。点开这个下拉框，None 在最后一项。选好后，下面的姓名和账单地址照常填写，State 选 **Oregon（OR）**，City、ZIP 和电话也填 Oregon 的，和 State 对得上，再点 Save Changes。

<a id="apple-billing-oregon"></a>

**免税州设置：** 美区 Apple ID 的账单州选择 **Oregon（OR）**。[Oregon 州税务局](https://www.oregon.gov/dor/programs/businesses/Pages/sales-tax.aspx)明确说明该州不征一般销售税，因此 ChatGPT iOS 内购应按页面标价 $19.99 结算。设置完成后，付款前再确认结算页总额确实是 $19.99。

这一步不能省。Apple 在美国按账单地址收销售税，州、县、市、区都按账单地址认定（见 Apple 开发者文档的[交易税报告字段说明](https://developer.apple.com/help/app-store-connect/reference/transaction-tax-report-fields)）。$20 礼品卡付完 $19.99 只剩 $0.01，账单地址在收税的州，加上税就超过余额，付款时会提示「必须提供付款信息才能继续购买」，处理办法见[下文](#apple-payment-info-required)。

<a id="apple-id-none-missing"></a>

##### 看不到 None 怎么办

按下表从上往下排查。第 2 到第 5 条依据 Apple 官方支持文章：[更改 Apple 账户国家或地区](https://support.apple.com/zh-cn/118283)、[从 Apple 账户中移除付款方式](https://support.apple.com/zh-cn/118291)。

| 先查什么 | 为什么没有 None | 怎么处理 |
| --- | --- | --- |
| 1. 有没有点开 Payment Type | None 收在下拉框里，默认显示的是 Credit / Debit Card | 点开下拉框，看最后一项 |
| 2. 当前是不是在美国 | Apple 的说明是：改区时可能要为新地区填付款方式，不想填的话，要等本人到了那个国家或地区再操作。Apple 没写怎么判断位置，我的经验是开着美国节点时能看到 None | 开美国节点的全局模式，退出 account.apple.com 重新登录，再改一次 |
| 3. 账号有没有欠款 | 有未付款项时，Apple 可能不让移除付款方式，只能更换 | 改区前先在原地区把欠款付清（例如国区账号绑支付宝或微信付掉），再改 |
| 4. 有没有生效中的订阅 | 有 iCloud+ 等订阅时，账号必须至少保留一种付款方式 | 设置 → 你的姓名 → 订阅，全部取消，等当前订阅期结束再改 |
| 5. 有没有加入家人共享 | 家庭组织者开着「购买项目共享」时必须保留付款方式；家庭成员可能根本改不了地区 | 组织者先关掉「购买项目共享」；成员先退出家庭组 |
| 6. 选了 None，保存不了 | 账单信息没填全 | 姓名、街道、城市、State、5 位邮编、电话逐项填好，State 选 Oregon（OR），城市和邮编也用 Oregon 的 |

**都排除了还是没有 None？** 换一个新注册的 Apple ID，专门用于美区 App Store，也就是上面推荐的做法。Apple 对不想填付款方式的人，给的办法也是到当地后新建账户；Apple 的[创建账户说明](https://support.apple.com/zh-cn/108647)里，填付款方式这一步同样可以选「无」。注册和第一次登录 App Store 时都开着美国节点。

**点 Continue 后提示无法更改地区？** 这一步和 None 无关。按 Apple 的说明，先用完账户余额，取消订阅并等订阅期结束，等会员资格、预购、影片租借和退款都处理完；余额少于一件商品价格的，联系 Apple 支持清零。

**改的是国区 Apple ID？** Apple 中文版说明写明：把地区从中国大陆改到其他国家或地区，等于同意云上贵州把你的 iCloud 内容转移到境外的 Apple 服务器，转移完成后删除境内服务器上的内容。不想动主力 iCloud，就用单独的美区 Apple ID。

2026 年 10 月 11 日和 16 日都有读者在 [Issue #1](https://github.com/Avarce/chatgpt-plus-china-guide/issues/1) 反馈这一步没有 None，这一节是据此重写的。

准备好以后，往下看兑换和订阅；还没买卡的话，可以回到[买卡渠道](#buy-gift-card)。

<a id="apple-redeem-subscribe"></a>

#### 拿到兑换码后：兑换，再订阅

1. **找兑换码。** 兑换码会发到下单时填的邮箱；没收到也不用急，在 Pockyt Shop 底部的「订单」里能看到这笔购买记录和兑换码。在 SEAGM 买的，兑换码在「我的卡密」里，见[上面第 ⑭–⑰ 步](#seagm)。
2. **兑换。** App Store → 右上角头像 → Redeem Gift Card or Code（中文界面是「兑换代码」），把兑换码充入美区 Apple ID。兑换后，余额会显示在名字下面。
3. **订阅。** 在 iOS 版 ChatGPT App 登录要升级的 OpenAI 账号 → Upgrade → 使用 Apple ID Balance 完成付款，付款前确认总额是 $19.99。

<a id="apple-new-account"></a>

**新注册的美区 Apple ID：可以先买一两个便宜 App，再订 Plus。** 这是我们的经验，不是 Apple 写明的规则：刚建好的账号，第一笔就用余额付 $19.99，比较容易卡住，弹出「购买未完成，提交申请至 Apple 支持以供审核」。先在 App Store 搜「0.99」，挑一两个便宜的 App 买下来，下载打开用一用，让账号有一些正常的购买和使用记录，再去订 Plus。这样做不保证一定不被审核，只是让账号看起来更像正常在用。

<p align="center">
  <img src="images/apple-new-account-cheap-apps-20261106.jpg" width="300" alt="美区 App Store 搜索 0.99，结果里有 $0.99、$0.29 的付费 App，新注册的美区 Apple ID 可以先买一两个便宜 App">
</p>

**订阅成功了？** 这条路线下个月续费前还要再充一次礼品卡。点一下右上角的 Star，下次好找回来；价格和入口有变化，也会更新在这里。

**想用礼品卡在 iPhone 上订 Pro？** 美区 App Store 的 ChatGPT 页面（10 月 22 日）列有 Pro 100 $100、Pro 200 $200。按 [OpenAI 的说明](https://help.openai.com/en/articles/7905739-chatgpt-ios-app-upgrading-to-a-paid-subscription)，Free 直接升 Pro 要去网页端，所以在 iPhone 上只能先订 Plus，再升级 Pro。要注意，一次花 $100 以上，更容易被 Apple 拦下审核，弹出「购买未完成，提交申请至 Apple 支持以供审核」，刚注册或刚改到美区的 Apple ID 尤其容易遇到。新注册的账号先买一两个便宜 App（见[上文](#apple-new-account)），再正常订几个月 Plus，有了购买记录再充大额余额；被拦了按[「购买未完成」怎么办](https://github.com/Avarce/apple-purchase-not-completed)处理。

**付款时弹出「购买未完成，提交申请至 Apple 支持以供审核」？** 这是 Apple 的购买审核，先别反复点。处理步骤和找到 Apple 在线客服的入口见[「购买未完成」怎么办](https://github.com/Avarce/apple-purchase-not-completed)。

<a id="apple-payment-info-required"></a>

**付款时提示「必须提供付款信息才能继续购买」，点「继续」又跳到添加付款方式？** 礼品卡余额不够付这一笔，多半是账单地址不在 Oregon，$19.99 被加了销售税。不用绑卡，把账单地址改成 Oregon 就能用余额付。

2026 年 10 月 22 日有读者在 [Issue #1](https://github.com/Avarce/chatgpt-plus-china-guide/issues/1) 反馈：$20 礼品卡已经充进美区 Apple ID，在 ChatGPT App 里升级时提示「必须提供付款信息才能继续购买。请登录你的 Apple 账户，然后点『账单信息』，以提供付款信息」，点「继续」后进了「添加付款方式」，还是要绑卡。把账单地址改成 Oregon，城市、邮编和电话一起换成 Oregon 的之后，用 $20 余额付成功了。

为什么会这样：

- Apple 按账单地址加收销售税（见上文[免税州设置](#apple-billing-oregon)）。$20 付完 $19.99 只剩 $0.01，加了税，余额就不够了。
- 余额不够付全额时，Apple 会从你的主要付款方式扣费（[Apple 的 App、内容和订阅如何扣费](https://support.apple.com/zh-cn/118244)）。付款方式选的是 None，没有可扣的，就提示你先提供付款信息。

怎么处理：

1. 先看余额在不在这个 Apple ID 上：App Store → 右上角头像，有余额的话，金额显示在名字下面（[查看 Apple 账户余额](https://support.apple.com/zh-cn/119902)）。没有显示，说明礼品卡兑换到了别的 Apple ID。
2. 改账单地址：在 [account.apple.com](https://account.apple.com) 打开「付款与配送（Payment & Shipping）」，Payment Type 仍选 None，State 选 **Oregon（OR）**，City 和 ZIP 填 Oregon 的城市和它对应的邮编，电话也用 Oregon 的。用 iPhone 改，Apple 给的路径是：设置 → 你的姓名 → 付款与配送 → 编辑（[更改 Apple 账户付款方式](https://support.apple.com/zh-cn/118293)）。
3. 回 iOS 版 ChatGPT App 重新点 Upgrade，付款前确认总额是 $19.99。
4. 不想改地址的话，再兑换一张礼品卡，让余额够付含税的总额。
5. 余额够、地址也改了还是弹：Apple 写过，有些购买即使用余额付，也可能要求账户里登记一张信用卡（[Apple 礼品卡和余额能买什么](https://support.apple.com/zh-cn/118245)）。这种情况见[「购买未完成」怎么办的常见问题](https://github.com/Avarce/apple-purchase-not-completed#常见问题)。

**chatgpt.com 网页端的 Apple Pay 也让绑卡？** 正常。Apple 列出的余额用途是 App Store 里的 App、App 内购买和订阅，以及 apple.com 上的产品等（[Apple 礼品卡和余额能买什么](https://support.apple.com/zh-cn/118245)），不包括其他网站。网页结账里的 Apple Pay 用的是钱包里的银行卡，礼品卡余额只能在 iOS 版 ChatGPT App 里付。

**付款后仍显示 Free？** 先核对 ChatGPT 登录账号和登录方式，再到 App 内的 Settings → Restore purchases 恢复购买；这是 [OpenAI 官方的排查步骤](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)。

如果卡在付款或会员到账，可按具体提示查看 [ChatGPT 付款失败与订阅状态排查](https://aonir.com/guides/chatgpt-payment-failed/?utm_source=github&utm_medium=referral&utm_campaign=plus_guide&utm_content=ios_troubleshooting)，先定位问题再操作。

## 一个关键概念：掉订阅 ≠ 封号

这两件事经常被混为一谈，搞清楚能省你一堆焦虑：

- **掉订阅：** ChatGPT Plus 权益消失，账号本身不受影响，重新开一次就好。这跟「封号」是两回事。
- **封号（account deactivated）：** 账号被停用，聊天记录、自定义 GPT、记忆数据全部清零，申诉成功率很低。

真正导致封号的，几乎都是下面这几件事，而不是「代付」本身：

- 用了黑卡（盗刷信用卡）——个人小代充为了压价常干这个。
- 多人合租 / 共享账号——多地登录触发风控。
- 违规使用内容——踩了 OpenAI 使用政策的红线。
- 把账号密码交给不靠谱的人工代充。

只要你走正规渠道、绑自己账号、别贪便宜，封号概率其实很低，最坏情况通常是掉订阅。

- **判断要点：** 这一阶段的问题基本都是网络问题，跟你的卡没关系，别急着换卡。

### 阶段二：进了支付页，但付不进去

- **「您的银行卡被拒绝了」（Your card has been declined.）或「付款未获批」（Payment was not approved）：** 结账页不说原因。先看发卡银行在不在 OpenAI 支持的地区，中国大陆、香港、澳门不在（见[上文](#先搞明白为什么国内充-plus-这么难)），国内银行发的卡换支付方式（礼品卡 / 代充）才是正路。是支持地区的卡，再按 OpenAI 的顺序查：卡号、有效期、安全码和账单地址，银行有没有拦截境外交易，3D 验证有没有完成。7 种提示的原文对照见 [ChatGPT 付款未获批准怎么办](https://aonir.com/guides/chatgpt-payment-not-approved/?utm_source=github&utm_medium=referral&utm_campaign=plus_guide&utm_content=appendix_declined)。
- **提示需要验证，或 3D Secure 验证失败：** OpenAI 给的办法是允许弹窗和页面跳转、关掉广告拦截插件，用隐私模式或换浏览器、设备、网络再试；在银行短信或 App 里确认时，不要关闭或刷新结账页。还不行，请发卡银行为网上、境外交易开通 3D 验证，或者换一张卡（[Why was my credit card declined?](https://help.openai.com/en/articles/7232916-why-was-my-credit-card-declined)）。
- **Something went wrong, please try again later：** 常见于同一 IP 短时间内多次尝试、或卡段已被标记。别硬刚，换个思路（礼品卡 / 靠谱代充）比在这里死磕划算。
- **iOS 内购提示「必须提供付款信息才能继续购买」：** 用礼品卡余额付时最常见的原因是账单地址不在 Oregon，$19.99 加税后超过 $20 余额。不用绑卡，改账单地址就行，步骤见[路线 C 里这一段](#apple-payment-info-required)。

### 阶段三：付款过了，但会员没到 / 账号异常

- **扣款成功却没有 Plus 标识：** 先完全退出重新登录或换无痕；再确认你充的是哪个邮箱（多账号很容易付错号）；还没有就去邮箱搜 OpenAI 的收据邮件，确认到底扣款没有。
- **礼品卡兑换提示 This code has already been redeemed：** 这张卡已经被兑换过。来源不明的低价卡密容易遇到这种情况；从有公司主体、能查订单的渠道买（本文实测的 Pockyt、SEAGM），风险小得多。买到这种卡，先联系卖家。
- **Your account has been deactivated：** 分两种——充值前就被封的，多是网络/滥用/违规内容触发，可发邮件申诉但成功率不高；充值后被封的，大概率跟黑卡、人工代充交号、或多人共享有关。这也是本文反复强调「别贪便宜」的原因。

## 一句话总结

国内自己开 ChatGPT Plus，难点主要在两处：付款方式和网络环境。国内银行发的卡不在 OpenAI 支持范围内，反复尝试一般也过不了。比较现实的做法：有海外卡的走官方，有苹果设备的走美区礼品卡，其他朋友可以找一个靠谱的自助平台，把付款这一步交出去。

不管选哪条路，都需要一个稳定、能正常访问 ChatGPT 官网的网络环境。
